# RnR v0.4.3 — ความสามารถของ Compendium และ Session 0

## ความสามารถใน Compendium
- **Extra Skills (616):** ทุกตัวมีผลอัตโนมัติ
  - +1 ให้ 2 Skill ที่เข้ากับชื่อ ครอบคลุมครบทั้ง 31 Skill
  - ชื่อที่มีคำว่า Reaction ให้ป้องกันได้ 2 ครั้งต่อเทิร์น
  - สาย Combat (Action / Bonus Action) ทอยโจมตีได้
  - สาย Science รักษาคน (Medicine) หรือซ่อมเครื่องจักร (Electronic / Mechanical)
  - สาย Physical (Free Action) เพิ่ม Speed +5 ft
- **Abilities 36 / Spells 36 / Consumables 33:** แทนข้อความ “GM ตัดสิน” ด้วยกติกาที่มีตัวเลขชัดเจน พร้อมสูตรโจมตี ดาเมจ หรือรักษาที่กดใช้ได้
- **Classes 40:** ได้ Class Skill +1 ใน 2 Skill (อัตโนมัติ) และ Class Feature คนละแบบ
  - Scholar ที่ซ้ำกันเปลี่ยนชื่อเป็น Sage
- **Equipment 20 ชิ้น:** มีช่องสวมใส่และโบนัส Skill ที่ใช้งานได้ตอนสวม
- **Weapons 30 ชิ้น:**
  - แก้อาวุธประชิด 6 ชิ้นที่ถูกตั้งเป็นอาวุธยิง (จะขอกระสุน)
  - แก้ชนิดดาเมจและลูกเต๋าให้สมเหตุผล (เช่น Greatsword 2d6)
- **Armor:** ชิ้นเสริม (Helm, Gloves, Boot Guards…) ใส่ในช่องของตัวเองได้แล้ว และให้ DR +1 หรือโบนัส Skill เพื่อไม่ให้ DR ซ้อนกันสูงเกินไป

## แก้ bug
- โบนัส Skill จากอุปกรณ์ที่สวมอยู่แสดงบน Sheet แต่ไม่ถูกนับตอนทอย ตอนนี้ใช้ฟังก์ชันเดียวกัน
- GM ให้ Growth Points และ Extra Skill Points ไม่ได้จาก Sheet ตอนนี้ใส่ได้ในหน้าต่างเดียวกับ XP (ปุ่ม ＋ ข้างแถบ XP)

## Compendium ใหม่: RnR — Session 0
- **เรื่องเล่าฝึกหัด “เวรแรกที่ประตูฮาร์โรว์”** (12 หน้า, GM เท่านั้น): 9 ฉาก แต่ละฉากสอนกลไกของ RnR หนึ่งเรื่อง พร้อมค่าสถานะ NPC และตารางปรับแนวเรื่อง
- **คู่มือ GM: อธิบายผู้เล่นทีละขั้น** (10 หน้า, GM เท่านั้น): แผนเวลา, บทพูด, ตาราง, FAQ และเช็กลิสต์
- **เอกสารแจกผู้เล่น** (1 หน้า, ผู้เล่นเปิดอ่านได้)

## ความเข้ากันได้
- ไม่เปลี่ยน `_id` ของไอเทมใน Compendium
- ไอเทมที่นำเข้า World ไปแล้วไม่ถูกแก้ ต้องลากใหม่จาก Compendium ถ้าต้องการรุ่นใหม่
- โบนัส Class ใช้กับ Class ที่เพิ่มใหม่เท่านั้น
